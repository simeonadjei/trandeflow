Server-side continuous operation

Server-side continuous operation
Yes to both — the bot runs entirely on the server, not in your browser. Closing the tab changes nothing; it keeps scanning and trading.

There's one important caveat though: right now the server runs inside Replit's development environment, which goes to sleep when the workspace is idle for a while. So if you close everything and leave it, Replit may suspend the server after some period of inactivity, and the bot pauses until it wakes back up.

To run it truly 24/7 — you need to deploy the app. Once deployed, the API server runs on its own cloud instance that never sleeps, regardless of whether you or anyone else has the browser open.

The bot also has a built-in resume — if the server restarts for any reason, it automatically checks the database on startup and resumes your session if it was active when it went down. So you won't lose your session across restarts.
